# Algae Farm

Jogo didático em português para uma aula de Engenharia Bioquímica sobre microalgas, biodiesel e bioplásticos.

Jogar: https://candidomolino.github.io/algae-farm/

Uma missão de seis minutos combina exploração de uma fazenda com decisões de cultivo, energia, processamento e recuperação. Escolha uma encomenda de biodiesel ou placas com biomassa integral ou amido.

Os valores são fichas didáticas, sem equivalência direta com kg, kWh, litros ou desempenho industrial. As duas rotas não têm unidades de produto comparáveis. O jogo não calcula emissões nem certifica produtos.

O arquivo index.html contém o jogo completo, incluindo os desenhos. Não há cadastro ou envio de resultados pelo jogo; o progresso fica no navegador quando o armazenamento local está disponível. O provedor de hospedagem pode registrar os acessos ao site.

Versão do modelo: 0.1.0. Protótipo para revisão docente e piloto antes de uso em aula.
